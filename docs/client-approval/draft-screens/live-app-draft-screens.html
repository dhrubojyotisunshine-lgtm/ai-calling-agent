Open questions and next steps

  1. Is this the right base? These screens improve the existing Voxura app instead of designing a new one from scratch. Please confirm this is the plan.
  2. Do we have access to the source code of the live app (front end and backend)? We need it to know whether pausing, scheduling, recordings and outcomes already exist on the backend.
