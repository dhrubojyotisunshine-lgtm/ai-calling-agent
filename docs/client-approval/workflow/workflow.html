3. How one AI call works

The voice engine is the part that actually talks. The web app already stores everything it needs; the engine starts once the provider accounts are ready.

Before dialling: safety checks

Calling hoursOnly inside the campaign's hours (India time).
Do not callDND leads skipped; callbacks to DND leads blocked.
WalletBalance must be above ₹0; calls stop at ₹0.
LinesNo more calls at once than the agent and number allow.
No double callingA lead in another active campaign is skipped.

During the call

1. ConnectPhone line (SIP) or browser joins a live audio room (LiveKit).
→
2. ListenSpeech to text (Deepgram / Sarvam), Hindi, English, Hinglish.
→
3. ThinkAI brain (Claude, optionally others) uses the script, knowledge, lead details and memory.
→
4. SpeakText to natural voice (Sarvam), in under a second.
QualifyAsks need, budget, timeline; scores Hot / Warm / Cold.
BookOffers free calendar slots and books a meeting.
Hand overTransfers to a salesperson with a short summary.
Live monitorStaff can listen in or take over.

After the call

SavedTranscript, summary, outcome, recording, duration.
Lead updatedStage, memory of the conversation, next follow-up.
Charged onceWallet charged per call; can never double-charge.
RetryNo answer → tried again after the set gap, up to the set number of times.
Outgoing calls
  • From a campaign, a scheduled agent callback, or (designed) instantly when a new enquiry arrives.
Incoming calls
  • Each number has exactly one answering agent (rule already enforced). The agent greets, helps, takes messages, creates follow-ups.
Needs before real calls: LiveKit, Deepgram, Sarvam and Claude API accounts (browser test calls); an Indian SIP provider for phone numbers; a server (VPS) to run it.

5. Money flow and the Super Admin

How money moves, and how Voxura runs the business. Designed in the Super Admin draft; the wallet ledger already works.

Money flow for every call

Client pays inWallet top-up (Razorpay), plan fee, number rent
→
Call is chargedBillable time × client's ₹/min rate, once per call
→
Our real costAI brain + speech to text + voice + telephony

Margin = what the client was charged − what the providers cost us. It is stored on every call and added up per client, provider and month. Provider rates are dated, so a price change never alters past calls. Money entries are never edited, only reversed.
